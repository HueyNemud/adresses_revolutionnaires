Visionneuse OCR

Déposez ici le JSON de l'OCR (<document>.ocr.json, sortie de latynna) et, si vous l'avez, le PDF du volume : la transcription s'affiche en surimpression du scan.

Les fichiers restent sur cet ordinateur : rien n'est envoyé. Sans PDF, les blocs et les lignes s'affichent sur une page blanche.

    Visionneuse OCR

    Chaque ligne de l'OCR est un <span> qui porte la confiance de ses mots et une boîte estimée (elle peut tomber à côté d'un cran). Survoler une ligne la montre des deux côtés ; un clic y amène l'autre vue. Mots sous le seuil : surlignés ; ligne soulignée en pointillés : sans boîte.

    ← →page précédente / suivante
    Maj+← →page précédente / suivante avec des mots douteux (ou, pendant une recherche, avec un résultat)
    + − 0zoomer, dézoomer, pleine largeur
    B L Tblocs, lignes, texte sur le scan
    /rechercher (sans tenir compte des accents ni de la casse)

    Numérotation. Page du PDF = page_index + (0 pour un JSON de numrev ocr, où page_index est déjà la page du PDF ; 1 pour la sortie brute de latynna ocr sur tout le PDF, qui compte depuis 0).

    Partager. Envoyer ce fichier HTML avec le JSON et le PDF ; ou les publier ensemble sur un serveur web et donner le lien ocr.html?json=…&pdf=…#p=12.
